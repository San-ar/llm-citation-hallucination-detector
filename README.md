# LLM Citation Hallucination Detector

A hybrid validation pipeline designed to detect "hallucinated" academic citations in LLM responses. This system cross-references extracted DOIs and Paper Titles against the **OpenAlex API** and performs fuzzy string matching to calculate a probability score for hallucination.

## Overview

Large Language Models (LLMs) frequently invent plausible-sounding academic citations that do not exist in reality. This project provides a programmatic way to verify these citations by:

1.  **Extraction:** Identifying DOIs and Titles using complex Regex patterns from raw LLM text.
2.  **External Validation:** Verifying DOIs via the OpenAlex API and direct DOI resolution (Signal 1).
3.  **Internal Validation:** Comparing extracted titles with verified metadata using `RapidFuzz` (Signal 2).
4.  **Hybrid Classification:** Fusing both signals into a final weighted score for high-accuracy detection.



## The Hybrid Logic

The model uses a weighted formula to determine the `Predicted_Hallucination` state:

$$Hybrid\_Score = (0.7 \times Signal_{OpenAlex}) + (0.3 \times Signal_{Title})$$

* **Signal_OpenAlex (70%):** Weighted higher because a non-resolving or mismatched DOI is a high-confidence indicator of a hallucination.
* **Signal_Title (30%):** Acts as a safety net to catch cases where the DOI might be real, but the LLM has "hallucinated" the paper's title or the specific context of the research.

## The Dataset Contribution

A core component of this project is a custom-curated dataset of LLM-generated academic citations. This dataset serves as the ground truth for evaluation and includes:

* **Prompt_ID:** Unique id for the prompts.
* **Difficulty:** Complexity of the query.
* **Input_Prompt:** The specific request sent to the LLM.
* **Paper_Title_Verified:** The ground truth title of the paper (if it exists).
* **Expected_DOI:** The actual DOI for the paper (if it exists).
* **Hallucination_Type:** Categorized levels of "invention" (e.g., real DOI with fake title, or entirely fictitious data).
* **Ground_Truth:** Manually verified labels (0 = Valid, 1 = Hallucinated) for every entry.
* **Full_Response:** Raw text generated by various LLM models.
* **Extracted_DOI:** Systematically parsed DOIs.
* **Extracted_Titles:** Systematically parsed titles.

This dataset was created to address the lack of specialized benchmarks for citation-specific hallucination detection.



## Evaluation & Metrics

The system includes a full evaluation suite to visualize the effectiveness of the hybrid approach versus single-signal detection.

### Performance Visualizations
* **Confusion Matrix:** Displays the breakdown of True Positives (correctly identified hallucinations) vs. False Positives.
* **Ablation Study:** A comparative bar chart showing how the **Hybrid Model** outperforms using only the OpenAlex or only the Fuzzy Title signal.

### Key Metrics Tracked
* **Precision:** Accuracy of the flagged hallucinations.
* **Recall:** Ability to catch all hallucinations in the dataset.
* **F1-Score:** The harmonic mean of Precision and Recall.
* **ROC-AUC:** Overall diagnostic ability of the classifier.
